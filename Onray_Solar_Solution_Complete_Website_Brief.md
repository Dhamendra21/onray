# Onray Solar Solution --- Complete Website Design & Content Brief

## 1. Brand Identity

**Brand Name:** Onray Solar Solution

### Brand Positioning

Onray Solar Solution is a modern solar installation brand focused on
helping Indian homes and businesses turn unused rooftops into productive
clean-energy assets.

### Brand Personality

-   Modern
-   Premium
-   Trustworthy
-   Engineering-focused
-   Human
-   Sustainable
-   Local and accessible
-   Technology-driven

### Core Brand Message

> **YOUR ROOF IS READY. ARE YOU?**

Supporting message:

> Clean energy. Lower electricity costs. A smarter rooftop.

### Creative Direction

The website should feel like a combination of:

-   Premium architecture/editorial website
-   Modern technology brand
-   Solar engineering company
-   Cinematic storytelling experience

It should NOT look like a typical solar dealer website filled with
cards, gradients, stock photos and generic marketing copy.

# 2. Typography System

The typography is a major part of the Onray Solar Solution identity.

Instead of using only one sans-serif font, use a strong contrast between
a modern sans-serif and an editorial serif.

## Primary Heading Font --- Manrope

**Purpose:** Engineering, technology, confidence and strong visual
hierarchy.

### Use for

-   Hero headlines
-   Main section headings
-   Navigation where appropriate
-   Large numbers
-   Project titles
-   CTA headings
-   Important labels

### Recommended weights

-   600 --- SemiBold
-   700 --- Bold
-   800 --- ExtraBold

Example:

``` text
WE TURN
```

------------------------------------------------------------------------

## Editorial Storytelling Font --- Instrument Serif

**Purpose:** Human storytelling, elegance, emotion and premium editorial
character.

Use the italic style heavily but selectively.

### Use for

-   Key storytelling words
-   Emotional statements
-   Hero accent words
-   Short editorial phrases
-   Customer-story highlights

Example:

``` text
rooftops
```

or:

``` text
clean energy.
```

### Typography combination

``` text
WE TURN
rooftops
INTO
energy.
```

Manrope creates confidence.

Instrument Serif creates emotion.

Together they make the brand feel premium and distinctive.

------------------------------------------------------------------------

## Body Font --- Inter

**Purpose:** Readability and usability.

Use for:

-   Paragraphs
-   Descriptions
-   Forms
-   FAQs
-   Navigation
-   Buttons
-   Technical information
-   Supporting text
-   Footer

### Recommended weights

-   400 --- Regular
-   500 --- Medium
-   600 --- SemiBold
-   700 --- Bold

------------------------------------------------------------------------

## Recommended Type Scale

  Element             Font                         Weight     Desktop
  ------------------- ------------------------- --------- -----------
  Hero H1             Manrope                         800   72--104px
  Hero Serif Accent   Instrument Serif Italic     Regular   80--120px
  H2                  Manrope                         700    48--64px
  H3                  Manrope                         700    32--40px
  H4                  Manrope                         600    24--28px
  Body Large          Inter                           400        20px
  Body                Inter                           400    16--18px
  Small               Inter                           500    13--14px
  Navigation          Inter                           500    14--16px
  Button              Inter                           600    14--16px
  Large Numbers       Manrope                         800    56--80px
  Metadata            Inter                           500    10--12px

### Typography Rule

Use the serif font for **short emotional words**, not entire paragraphs.

Good:

> **WE POWER**\
> *rooftops*\
> **INTO**\
> *energy.*

Avoid:

> A complete paragraph written in Instrument Serif.

## Main Animation Technology

**GSAP + ScrollTrigger**

**Lenis**

## Recommended Effects

-   Text reveal
-   Image reveal
-   Image masking
-   Parallax
-   Sticky storytelling
-   Scroll progress
-   Number counters
-   Before/after image wipe
-   Energy-flow animation
-   Subtle scale transitions

## Animation Philosophy

Animation should communicate the story.

Do not animate everything.

Avoid:

-   Excessive bouncing
-   Random particles
-   Heavy 3D everywhere
-   Excessive floating elements
-   Long loading animations
-   Animation on every paragraph
